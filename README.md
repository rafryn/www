# Strona UKS Copernicus Toruń – Akademia Michała Kwiatkowskiego

Wersja testowa: https://rafryn.github.io/www/

## Co gdzie jest
| Co zmieniasz | Plik |
|---|---|
| Dane kontaktowe, włączenie/wyłączenie wersji testowej | `_config.yml` |
| Pozycje w menu | `_data/menu.yml` |
| Partnerzy i logotypy | `_data/partnerzy.yml` |
| Aktualności | folder `_posts` – instrukcja: `docs/JAK-DODAC-WPIS.md` |
| Podstrony | `index.html`, `o-klubie/`, `aktualnosci/`, `partnerzy/`, `zapisy/` |
| Kolory i wygląd | `assets/css/style.css` (na górze pliku) |
| Zdjęcia | `assets/img` |

## Jak to działa
GitHub Pages sam buduje stronę z tych plików (Jekyll) po każdej zmianie – nie ma serwera, bazy danych ani wtyczek do aktualizowania.
